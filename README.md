Task27- Breast Cancer Classification – Confusion Matrix & Threshold Tuning

##  Project Overview

This project focuses on binary classification using the **Breast Cancer Wisconsin Dataset**.

A Logistic Regression model is trained to classify tumors as:

- **Malignant** – cancerous
- **Benign** – non-cancerous

The project also demonstrates how changing the **classification probability threshold** affects model performance.


##  Objectives

- Load the Breast Cancer Wisconsin Dataset without uploading a CSV file.
- Preprocess and standardize the data.
- Train a Logistic Regression classification model.
- Evaluate the model using a confusion matrix.
- Calculate Accuracy, Precision, Recall, and F1 Score.
- Test different probability thresholds.
- Compare model performance at different thresholds.
- Identify a suitable classification threshold.

## Conclusion

This project demonstrates how a Logistic Regression model can be used for breast cancer classification.

The confusion matrix provides a clear view of the model's correct and incorrect predictions, while threshold tuning demonstrates how changing the probability threshold affects Accuracy, Precision, Recall, and F1 Score.

This project helped develop a better understanding of classification evaluation, confusion matrices, probability thresholds, and model performance optimization.
